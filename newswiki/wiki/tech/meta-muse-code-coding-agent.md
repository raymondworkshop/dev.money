# [Meta发布编程智能体，剑指OpenAI和Anthropic](https://cn.wsj.com/articles/meta-releases-coding-agent-to-compete-with-openai-and-anthropic-f456c8aa)

## 核心观点
- Meta 发布了名为 Muse Code 的编程智能体，旨在通过极具竞争力的低成本定价挑战 [[hubs/OpenAI|OpenAI]] 的 Codex 和 [[hubs/Anthropic|Anthropic]] 的 Claude Code。
- 定价策略分为两档：一档与 Muse Spark 模型持平，另一档低价等级仅为每百万输出 tokens 0.20 美元（要求用户提供反馈），成本与 [[hubs/DeepSeek|DeepSeek]] 等中国模型相当。
- 该产品由原 ScaleAI 联合创始人汪滔领导的 Meta 超级智能实验室 (Meta Superintelligence Labs) 开发，该部门采取激进的人才招聘计划以吸引顶尖实验室人才。
- [AI Synthesis] Meta 试图通过“低价+反馈”的模式快速构建用户规模并优化模型，以应对投资者对其 AI 巨额资本支出 (Capex) 回报率的质疑。

## 核心要点
- Muse Code 定位为廉价替代品，直接切入编程智能体市场。
- Meta 正在通过组织架构调整（成立超级智能实验室）和激进定价来抢占 AI 开发者生态。
- 市场对 Meta AI 投入的 ROI 极其敏感，产品商业化进展直接影响股价表现。
