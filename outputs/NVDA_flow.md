# NVDA：从价格和成交量看买卖痕迹

**结论: 中性（买卖不明显）**

## 理由
- 近50天：上涨天与下跌天的成交量差不多（比值 1.24，接近 1）。买卖力量大致相当，没有一边倒。
- 近8周没有明显的「高位收盘 + 成交量放大」买盘周。
- 近8周没有明显的「低位收盘 + 成交量放大」卖盘周。
- 中间下跌的几周，成交量大多偏小（轻量下跌 1 周、放量下跌 0 周）。更像暂时歇一歇，不像急着出货。
- 近15天有 2 天「大跌且量大」，算早期提醒，还不算很严重。

## 数字摘要
- 数据截至: 2026-09-04
- 用了多少个交易日: 252
- 近50天「上涨天成交量 / 下跌天成交量」: 1.24（大于 2 偏强买；小于 1 偏强卖；接近 1 差不多）

- 近8周里「像在买」的周 / 「像在卖」的周: 0 / 0

## 怎么判断的（白话）
- 先比：上涨那天总共成交了多少，相对下跌那天多还是少。
- 「像在买」的一周：收盘靠近当周最高价一侧（≥70%），且成交量至少是平时的 1.3 倍。
- 「像在卖」的一周：收盘靠近当周最低价一侧（≤30%），且成交量至少是平时的 1.3 倍。
- 「大跌且量大」的一天：当天跌至少 0.2%，成交量至少是平时的 1.3 倍。

> 这只是根据价格和成交量做的粗看，不是买卖建议。量大不一定等于大机构在动，也可能是 ETF 或短线交易。
