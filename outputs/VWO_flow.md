# VWO：最近是更像有人在买，还是有人在卖？

**结论: 稍微偏向有人在买**

## 理由
- 近50天：涨的日子和跌的日子，成交量差不多（数字 1.37，接近 1）。两边都差不多，看不出一边倒。
- 近8周里，没有出现这种一周：收盘靠近本周最高价，同时成交量又明显变大。
- 近8周里，没有出现这种一周：收盘靠近本周最低价，同时成交量又明显变大。
- 中间有几周价格往下走，但成交量大多不大（成交偏少的下跌周 2 个，成交很大的下跌周 0 个）。更像暂时歇一歇，不像急着卖掉。
- 近15天里，没有「跌得比较明显且成交量很大」的日子。

## 怎么判断的
- 先看近一段时间：涨的日子成交多，还是跌的日子成交多。
- 「更像在买」的一周：这一周结束时，收盘价靠近本周最高价（至少到从最低到最高的 70%），而且成交量至少是平时的 1.3 倍。
- 「更像在卖」的一周：这一周结束时，收盘价靠近本周最低价（只到从最低到最高的 30% 或更低），而且成交量至少是平时的 1.3 倍。
- 「跌得比较明显且成交量很大」的一天：当天至少跌 0.2%，成交量至少是平时的 1.3 倍。

## 数字摘要
- 数据算到: 2026-09-04
- 一共用了多少天的价格: 252
- 近50天：涨的日子成交量 ÷ 跌的日子成交量 = 1.37（大于 2 更像买得积极；小于 1 更像卖得积极；接近 1 差不多）
- 近50天平均每天成交多少: 7,238,316
- 近8周里「更像在买」的周数 / 「更像在卖」的周数: 0 / 0
- 近15天里「跌得比较明显且成交量很大」的天数: 0
